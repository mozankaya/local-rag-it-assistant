# Frontend

Bu dizin, İZELTAŞ IT Danışma Asistanı prototipinin React, TypeScript ve Vite tabanlı frontend uygulamasını içerir. Container dağıtımında uygulama Nginx ile sunulur ve tüm API istekleri yalnızca FastAPI üzerinden gerçekleştirilir.

Frontend; JWT tabanlı kimlik doğrulama, kullanıcı sohbet arayüzü ve admin arayüzünü sağlar.

## Geliştirme komutları

Çalışma dizini: `frontend/`.

```powershell
npm install
npm run dev
npm run lint
npm run build
```
